# EarPhones

EarphonesHub is a modern and responsive website for stylish earphones and audio accessories created using HTML, CSS, and JavaScript.  
The website showcases wireless earphones, gaming headsets, and music accessories with a clean and attractive user interface.

## Features
- Responsive design
- Product showcase section
- Modern homepage
- Navigation bar
- Interactive buttons
- Stylish product cards

## Technologies Used
- HTML
- CSS
- JavaScript
